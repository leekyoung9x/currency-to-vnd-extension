Budgets

Cap what you’ll pay. Set a budget by model name (applies across all providers that offer it) or fine-tune per provider model. Either set a hard max $/Mtok or a min % discount off official price. Optionally set a queue wait (default 30s) so inference holds for a concurrency slot instead of failing immediately. The proxy auto-injects these on every request; consumers can override per-request via the x-max-input-price / x-max-output-price headers.

Pick an API key to give it its own budget: requests made with that key use the key’s values, and anything the key leaves unset falls back to the account. An optional price floor skips offers cheaper than a given % off, which keeps long agentic runs on quieter providers with better cache hit rates. The floor never lets a request cost more than the budget; if nothing is left above it, it is ignored for that request.
